The program will start up and show the Menu with 4 options: 1. Add Items, 2. View Items, 3. Remove Items, and 4. Exit.
If 1 is selected, a new interface will pop up, asking the user to input the "item name" of what they are adding, then, after the user presses enter, a new line asking the "quantity" of said item to be added.
The program will then display a message telling the user the "quantity" of "itemname" was added and return back to the Main Menu with the 4 options, where the program started for a new selection.
If option 2 was selected, the program will display a text "Displaying items..." and return to the Main Menu.
If option 3 was chosen, the program will display a new line asking the player to enter the name of item to be removed.
When the user presses enter after entering the "item name", it will ask what "quantity" of the item is to be removed.
Then, it will tell the user "quantity" of "item name" has been removed.
Afterwards, the program will return to the Main Menu for yet another selection.
Lastly, if the user chose 4, the program will end.
