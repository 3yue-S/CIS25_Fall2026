The code asks the user to enter the amount of items that is to be added to the inventory.
After the user enters a number and presses enter, the program then displays the text "Enter details for the item" along with an ask to enter the name of the item under that.
Then, the user enters a name and presses enter, wherein the name gets stored.
The program then asks the user to enter the quantity of the item to be added. 
After the quantity is entered, the integer is stored and these two questions, name and quantity, repeat until the number of items reaches the number of items to be addded into the inventory in the first prompt.
Once that initial number is reached, the program displays the current inventory, all the saved names and quantities of items that have been added until this point.
If there are no items in the inventory list, the program displays the text "Inventory is empty."
The program then returns to its initial state.
