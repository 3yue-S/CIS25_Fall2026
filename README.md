When the code runs, it displays a message "Enter book ID to search: ", and allows for the user to enter a whole number into the system.
That number is then sored as targetId in the code and a binary search starts to find the item with the ID that matches the number the user entered, now known as targetId.
When it finds an item that does match the targetId, the code displays the message "Book found: " with the name of the item displayed after the colons.
If it does not find an item that matches the targetId, the interface displays the message "Book not found." 
After that, the entire inventory is deleted to free up space.
